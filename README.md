# Sound Physics

A Minecraft Forge 1.12.2 mod that provides realistic sound attenuation, reverberation, and absorption through blocks.

## Features

- Sound attenuation based on distance.
- Sound occlusion and absorption through blocks.
- Environment-based reverberation and echoes.
- Surface-dependent sound reflection.
- Underwater sound filtering.
- Air absorption and weather-dependent audio processing.
- OpenAL EFX filters and reverb effects.
- Automatic stereo-to-mono downmixing.
- Entity sound position correction.
- Server-side sound distance adjustment.

## Compatibility

This fork focuses on the core Sound Physics functionality.

No mod-specific patches or integrations are included.
